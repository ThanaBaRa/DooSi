# 🔮 ดูสิ.บาร่า (DooSi.BaRa) — เว็บเปิดไพ่พยากรณ์สุดปั่นแห่งปี 2026

ยินดีต้อนรับสู่ **ดูสิ.บาร่า (DooSi.BaRa)** เว็บแอปพลิเคชันสุ่มเปิดไพ่ยิปซีสายมีมสุดกวน ที่รวมคำทำนายสุดจัดจ้าน ทั้งหมวดชีวิตทั่วไป, ความรัก, และการเงินการงาน พร้อมระบบเสียงดนตรีบรรยากาศและดาวน์โหลดภาพคำทำนายพร้อมแชร์ลงโซเชียลมีเดีย

![DooSi Icon](icon.png)

## ✨ ฟีเจอร์เด่น
- 🃏 **สำรับไพ่ 3 หมวดหมู่**: หมวดชีวิตทั่วไป (General), หมวดความรัก (Love), และหมวดการเงิน/การงาน (Money)
- 🎴 **ระบบเลือกไพ่ 2 สไตล์**: เลือกเปิดแบบ 1 ใบด่วนทันใจ หรือ 3 ใบเรียงอดีต-ปัจจุบัน-อนาคต
- 🌀 **Interactive Ribbon & Grid**: มุมมองสำรับไพ่แบบพัดโค้ง (Fan Ribbon) เลื่อนสัมผัสได้อย่างลื่นไหล พร้อมปุ่มสลับมุมมองตาราง
- 🎶 **Ambient Sound Engine**: เสียงดนตรีคลื่นความถี่สร้างสมาธิและบรรยากาศเร้นลับวนลูปต่อเนื่อง
- 📸 **One-Click Shareable Card Generator**: ดาวน์โหลดการ์ดทำนายความละเอียดสูง (1200x690 สำหรับ 3 ใบ และ 860x790 สำหรับ 1 ใบ) พร้อมแชร์ลง Instagram Story, TikTok, หรือ Facebook
- 📊 **Real-time Live Stats**: แสดงสถิติจำนวนผู้เล่นและจำนวนครั้งที่เปิดไพ่

## 🛠️ เทคโนโลยีที่ใช้
- **Frontend**: HTML5, Modern CSS3 (Glassmorphism & Neon Glow), Vanilla JavaScript (Zero External Bloat)
- **Audio**: Web Audio API & HTML5 Audio
- **Canvas**: Native HTML5 2D Canvas สำหรับเรนเดอร์ภาพบันทึกคุณภาพสูง
